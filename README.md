# Test Project 2

A Node.js app built with **TypeScript** and **Next.js** (App Router).

## Tech stack

| Layer | Choice |
| --- | --- |
| Runtime | Node.js |
| Language | TypeScript |
| Framework | Next.js (App Router, React Server Components) |
| Config | `dotenv` |

## Requirements

- [Node.js](https://nodejs.org/) 18 or later
- npm (comes with Node.js)

## Setup

```bash
npm install
```

When the Next.js app is in place:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).
